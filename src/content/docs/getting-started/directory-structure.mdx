## Directory Roles

### `configs/` (`--configs-dir`)

Single directory for all server config files:
- `apis.yml` (can also be set via `-Dapis.config=<path>`)
- `server.properties`, `bukkit.yml`, `spigot.yml`, `commands.yml`, `permissions.yml`, `help.yml`
- `paper.yml`, `paper-global.yml`, `paper-world-defaults.yml`

### `addons/` (`--addons-dir`) and `plugins/` (`-P` / `--plugins`)

Apis splits executable JARs from plugin data:
- **`addons/`** - only directory scanned for plugin `.jar` files. Deferred updates go in `addons/update/`.
- **`plugins/`** - holds plugin configs and databases (`plugins/<PluginName>/`). **JAR files left in `plugins/` are skipped.**

:::tip
When `addons/update/` is empty, Apis skips opening plugin archives to check for updates on future starts.
:::

### `users/`

`usercache.json`, `ops.json`, `whitelist.json`, `banned-players.json`, and `banned-ips.json` live in `users/`. If any already exist in root from a previous Paper setup, Apis reads those automatically for compatibility.

### `cache/`

- **`cache/natives/`** - persistent cache for unpacked native libraries (`so`/`dylib`) so they are not re-extracted on every boot.
- **`cache/.paperclip-stamp`** - dependency integrity stamp that skips redundant SHA-256 hashing at startup.

## CLI Flags

| Flag | Default | Description |
| --- | --- | --- |
| `--configs-dir <Path>` | `configs` | Server config directory |
| `--worlds-dir <Path>` | `worlds` | Worlds container directory |
| `--addons-dir <Path>` | `addons` | Plugin `.jar` & `update/` directory |
| `-P`, `--plugins <File>` | `plugins` | Plugin configs & data directory |
| `-c`, `--config <File>` | `configs/server.properties` | Path to `server.properties` |
| `-b`, `--bukkit-settings <File>` | `configs/bukkit.yml` | Path to `bukkit.yml` |
| `-C`, `--commands-settings <File>` | `configs/commands.yml` | Path to `commands.yml` |
| `-S`, `--spigot-settings <File>` | `configs/spigot.yml` | Path to `spigot.yml` |
| `--paper`, `--paper-settings <File>` | `configs/paper.yml` | Path to legacy `paper.yml` |
| `--add-plugin`, `--add-extra-plugin-jar` | - | Extra plugin JARs outside `addons/` |
| `-Dapis.config=<Path>` | `configs/apis.yml` | JVM property for a custom `apis.yml` path |

:::note
If a legacy plugin crashes because it expects `server.properties`, `bukkit.yml`, or `ops.json` in root, Apis catches it and prints a short symlink hint pointing to `configs/` or `users/`.
:::
