Файл `configs/apis.yml` - це головний конфіг ядра Apis. У ньому зібрані вимикачі ігрових систем, режими світів, мережеві обмеження та шаблони повідомлень команд. Застарілі дублікати в `server.properties`, `bukkit.yml`, `spigot.yml` і `paper-*.yml` синхронізуються й автоматично прибираються, щоб усі налаштування керувалися з одного місця.

<CardGrid>
  <Card title="Раннє завантаження" icon="rocket">
    Файл `configs/apis.yml` зчитується на самому старті ще до ініціалізації світів і реєстрів, дозволяючи намертво вимкнути DataFixers, рецепти чи прогрів кешів блоків.
  </Card>
  <Card title="Шлях до конфігурації" icon="document">

  </Card>
  <Card title="Захист від пошкодження" icon="approve-check-circle">

## Повний довідник параметрів `configs/apis.yml`

Нижче наведено всі параметри 15 функціональних секцій (`Feature`-вимикачі, білі списки та числові межі). Для кожного ключа вказано тип, дефолтне значення та пов'язану константу `org.apismc.apis.feature.Feature` (або правило санітизації в `ApisConfig#sanitize`).

### `startup` - Холодний старт і перевірки

| Ключ | Тип | За замовчуванням | `Feature` / Примітка |
| --- | --- | --- | --- |
| `startup.datafixers` | `boolean` | `true` | `STARTUP_DATAFIXERS` - побудова схем DFU/DataConverter та міграція старих даних; при `false` і старому `DataVersion` світу виводиться стартовий `WARN` |
| `startup.search-spawn-point` | `boolean` | `true` | `STARTUP_SEARCH_SPAWN_POINT` - пошук поверхні у 11×11 чанках; `false` ставить `(0, seaLevel, 0)` |
| `startup.initial-chunk-load` | `boolean` | `true` | `STARTUP_INITIAL_CHUNK_LOAD` - активація `TicketStorage` і очікування стартових чанків до `Done` |
| `startup.mojang-service-discovery` | `boolean` | `true` | `STARTUP_MOJANG_SERVICE_DISCOVERY` - HTTP/DNS-запит до `discovery.minecraftservices.com` |
| `startup.paper-version-check` | `boolean` | `true` | `STARTUP_PAPER_VERSION_CHECK` - перевірка оновлень збірки на старті |
| `startup.validate-creative-tabs` | `boolean` | `true` | `STARTUP_VALIDATE_CREATIVE_TABS` - валідація `CreativeModeTabs` і `LootContextParamSets` у `Bootstrap` |
| `startup.validate-loot` | `boolean` | `true` | `STARTUP_VALIDATE_LOOT` - валідація таблиць луту в `ReloadableServerRegistries` |
| `startup.test-registries` | `boolean` | `true` | `STARTUP_TEST_REGISTRIES` - завантаження реєстрів GameTest (`test_environment`, `test_instance`) |

## Секція `messages.commands`

Усі 26 ключів мають тип `@Nullable String` і підтримують форматування **MiniMessage**. Якщо задати порожній рядок `""`, вивід відповідного повідомлення вимикається (`ApisMessageRenderer.render`).

| Ключ | Плейсхолдери | Значення за замовчуванням |
| --- | --- | --- |
| `no-permission` | - | `<red>You do not have permission to execute this command.` |
| `player-only` | - | `<red>Only players can run this command without explicit world/coordinates.` |

## Механізм `ApisConfigSync`

Щоб уникнути конфліктів між однаковими параметрами у спадкових файлах Vanilla, Bukkit, Spigot і Paper, клас `org.apismc.apis.config.ApisConfigSync` примусово перезаписує дзеркальні поля в пам'яті та **вирізає дублюючі ключі** під час запису конфігів на диск.

```d2 title="Синхронізація конфігів через ApisConfigSync"
direction: down

apis: "configs/apis.yml"
sync: "ApisConfigSync"
props: "server.properties\n(видаляє allow-nether,\nspawn-*)"
bukkit: "bukkit.yml\n(видаляє\nsettings.allow-end)"
spigot: "spigot.yml\n(видаляє advancements.*,\nplayers.disable-saving)"
paper: "paper-global.yml\nта paper-world*.yml"

apis -> sync: "Старт або /apis reload"
sync -> props
sync -> bukkit
sync -> spigot
sync -> paper
```

### Таблиця синхронізації та очищення

| Конфіг / Клас | Що перевизначається в runtime | Які ключі видаляються перед збереженням на диск |
| --- | --- | --- |
| `configs/server.properties` (`Settings.java.patch`) | Значення беруться з `apis.yml` | `allow-nether`, `spawn-monsters`, `spawn-animals`, `spawn-npcs` |
| `configs/bukkit.yml` (`CraftServer.java.patch`) | `CraftServer#getAllowEnd()` читає `!ApisHooks.isDimensionDisabled(Level.END)` | `settings.allow-end` (у конфігу та дефолтах) |
| `configs/spigot.yml` (`SpigotConfig.java.patch`, `Main.java.patch`) | `SpigotConfig.disableAdvancementSaving`, `disabledAdvancements` (`["*"]` або `[]`), `disablePlayerDataSaving` | `advancements.disable-saving`, `advancements.disabled`, `players.disable-saving` (та порожні секції `advancements`, `players`) |
| `configs/paper-global.yml` (`Configurations.java.patch`) | `GlobalConfiguration`: `misc.enableNether`, `collisions.enablePlayerCollisions`, `spark.enabled`, `spark.enableImmediately` (`false` при вимкненому Spark), `updateChecker.enabled` | `misc.enable-nether`, `collisions.enable-player-collisions` |
| `configs/paper-world*.yml` (`Configurations.java.patch`) | `WorldConfiguration`: `environment.disableThunder`, `environment.disableIceAndSnow`, `unsupportedSettings.ticking.chunks` | `environment.disable-thunder`, `environment.disable-ice-and-snow`, `unsupported-settings.ticking.chunks` |

:::tip
При виконанні `/apis reload` ядро автоматично викликає `ApisConfigSync.syncAll(server)`, що миттєво оновлює дзеркальні прапорці у `SpigotConfig`, `GlobalConfiguration` та всіх завантажених `ServerLevel#paperConfig()`.
:::
