## Призначення директорій

### `configs/` (`--configs-dir`)

Єдина папка для всіх налаштувань сервера:
- `apis.yml` (шлях можна також задати через `-Dapis.config=<шлях>`);
- `server.properties`, `bukkit.yml`, `spigot.yml`, `commands.yml`, `permissions.yml`, `help.yml`;
- `paper.yml`, `paper-global.yml`, `paper-world-defaults.yml`.

### `addons/` (`--addons-dir`) та `plugins/` (`-P` / `--plugins`)

В Apis виконуваний код плагінів відокремлений від їхніх налаштувань:
- **`addons/`** - єдина папка, звідки завантажуються `.jar`-файли плагінів. Папка відкладених оновлень (`update-folder`) також знаходиться тут - `addons/update/`.
- **`plugins/`** - папка для конфігів і баз даних (`plugins/<PluginName>/`). **JAR-файли, залишені всередині `plugins/`, ігноруються й не запускаються.**

:::tip
Якщо папка `addons/update/` порожня, Apis запам'ятовує це й не витрачає час на повторне відкриття JAR-архівів під час старту.
:::

### `users/`

Файли `usercache.json`, `ops.json`, `whitelist.json`, `banned-players.json` та `banned-ips.json` зберігаються в `users/`. Якщо ці файли вже лежать у корені сервера з попередніх версій, Apis автоматично використає їх для сумісності.

### `cache/`

- **`cache/natives/`** - постійне сховище розпакованих нативних бібліотек (`so`/`dylib`), щоб не витягувати їх заново при кожному запуску.
- **`cache/.paperclip-stamp`** - кеш перевірки цілісності бібліотек, який пропускає зайвий перерахунок SHA-256 при старті.

## Аргументи командного рядка (CLI-прапорці)

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--configs-dir <Path>` | `configs` | Папка конфігурацій сервера |
| `--worlds-dir <Path>` | `worlds` | Контейнер світів |
| `--addons-dir <Path>` | `addons` | Папка для `.jar`-файлів плагінів та `update/` |
| `-P`, `--plugins <File>` | `plugins` | Папка для конфігів і даних плагінів |
| `-c`, `--config <File>` | `configs/server.properties` | Шлях до `server.properties` |
| `-b`, `--bukkit-settings <File>` | `configs/bukkit.yml` | Шлях до `bukkit.yml` |
| `-C`, `--commands-settings <File>` | `configs/commands.yml` | Шлях до `commands.yml` |
| `-S`, `--spigot-settings <File>` | `configs/spigot.yml` | Шлях до `spigot.yml` |
| `--paper`, `--paper-settings <File>` | `configs/paper.yml` | Шлях до legacy `paper.yml` |
| `--add-plugin`, `--add-extra-plugin-jar` | - | Додаткові JAR-файли плагінів поза `addons/` |
| `-Dapis.config=<Path>` | `configs/apis.yml` | Системна властивість JVM для власного шляху до `apis.yml` |

:::note
Якщо застарілий плагін падає з помилкою через те, що не знаходить у корені `server.properties`, `bukkit.yml` або `ops.json`, Apis виведе в консоль коротку підказку про створення символічного посилання на `configs/` або `users/`.
:::
