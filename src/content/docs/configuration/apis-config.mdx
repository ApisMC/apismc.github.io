import { Card, CardGrid } from "@astrojs/starlight/components";

`configs/apis.yml` is the main config file for Apis. It centralizes gameplay kill-switches, world modes, packet range limits, and command message templates. Overlapping keys in `server.properties`, `bukkit.yml`, `spigot.yml`, and `paper-*.yml` are synced in memory and stripped on disk so settings live in one place.

<CardGrid>
  <Card title="Early Loading" icon="rocket">
    `configs/apis.yml` loads right at startup before worlds or registries initialize, so DataFixers, recipes, and block cache warmups can be disabled up front.
  </Card>
  <Card title="Config Path" icon="document">
    Stored at `configs/apis.yml` by default. Pass `-Dapis.config=<path>` on startup to point to another file.
  </Card>
  <Card title="Broken YAML Guard" icon="approve-check-circle">
    If your YAML has a syntax error, the server will not crash. It moves the broken file to `configs/apis.yml.broken` and writes a clean default config.
  </Card>
  <Card title="Simple Booleans" icon="setting">
    Straight `true` / `false` logic: `true` keeps vanilla Paper behavior, while `false` turns the subsystem off to save CPU and RAM.
  </Card>
</CardGrid>

## Full `configs/apis.yml` Reference

## How `ApisConfigSync` Works

To stop duplicate settings across Vanilla, Bukkit, Spigot, and Paper configs from drifting out of sync, `org.apismc.apis.config.ApisConfigSync` overwrites mirrored in-memory fields and **strips overlapping keys** before writing legacy files to disk.

```d2 title="Config Sync via ApisConfigSync"
direction: down

apis: "configs/apis.yml"
sync: "ApisConfigSync"
props: "server.properties\n(strips allow-nether,\nspawn-*)"
bukkit: "bukkit.yml\n(strips\nsettings.allow-end)"
spigot: "spigot.yml\n(strips advancements.*,\nplayers.disable-saving)"
paper: "paper-global.yml\nand paper-world*.yml"

apis -> sync: "Boot or /apis reload"
sync -> props
sync -> bukkit
sync -> spigot
sync -> paper
```

### Sync & Stripping Matrix

| Config / Class | Runtime Overrides | Keys Stripped Before Disk Save |
| --- | --- | --- |
| `configs/server.properties` (`Settings.java.patch`) | Values read from `apis.yml` | `allow-nether`, `spawn-monsters`, `spawn-animals`, `spawn-npcs` |
| `configs/bukkit.yml` (`CraftServer.java.patch`) | `CraftServer#getAllowEnd()` reads `!ApisHooks.isDimensionDisabled(Level.END)` | `settings.allow-end` (in both config and defaults) |
| `configs/spigot.yml` (`SpigotConfig.java.patch`, `Main.java.patch`) | `SpigotConfig.disableAdvancementSaving`, `disabledAdvancements` (`["*"]` or `[]`), `disablePlayerDataSaving` | `advancements.disable-saving`, `advancements.disabled`, `players.disable-saving` (plus empty `advancements` / `players` sections) |
| `configs/paper-global.yml` (`Configurations.java.patch`) | `GlobalConfiguration`: `misc.enableNether`, `collisions.enablePlayerCollisions`, `spark.enabled`, `spark.enableImmediately` (`false` when Spark is off), `updateChecker.enabled` | `misc.enable-nether`, `collisions.enable-player-collisions` |
| `configs/paper-world*.yml` (`Configurations.java.patch`) | `WorldConfiguration`: `environment.disableThunder`, `environment.disableIceAndSnow`, `unsupportedSettings.ticking.chunks` | `environment.disable-thunder`, `environment.disable-ice-and-snow`, `unsupported-settings.ticking.chunks` |

:::tip
Running `/apis reload` calls `ApisConfigSync.syncAll(server)` right away, updating mirrored flags inside `SpigotConfig`, `GlobalConfiguration`, and every loaded `ServerLevel#paperConfig()`.
:::
